Personal Nest integration

This website describes the Home Assistant OAuth application operated by the GitHub account merewords for personal household use.

What the application does

The integration connects authorised Google Nest devices to the operator’s private Home Assistant installation. Depending on supported devices and permissions granted, it can display camera live streams, receive device events and monitor or control thermostats.

Google handles account sign-in and consent. The account holder chooses which supported devices and permissions to authorise. This is a personal integration, not a public service accepting registrations.

About these pages

This public website contains information only. It provides no access to the private dashboard, cameras or Google account. It is independently operated and is not an official Google or Home Assistant project website.

Read the privacy policy for data handling information. For questions, use the support email displayed on the Google OAuth consent screen.
